# The Dog Reviews the Mailman

A tiny Node 22 program for the make.fun competition
**"The Dog Reviews the Mailman"**.

It writes one funny one-line review — a dog's verdict on the mailman —
to `/output/entry.txt` (1–200 characters, a single line).

## Run

```sh
node main.ts
```

The review it writes:

> Five stars for the mailman: he comes every day, lets me bark him off the porch, and never once asked why I lick the envelopes. Best nemesis ever.

## Files

- `main.ts` — the entrypoint; writes and validates the review.
- `DESIGN.md` — why this joke, and how it meets the judge's brief.
